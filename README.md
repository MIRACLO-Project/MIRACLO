# MIRACLO

*Pure Android 17, made to feel like yours.*

**MIRACLO 1.0 "Aurora"**: a clean Qualcomm (CLO) Android 17 ROM for the **POCO F5 (marble)**, with **Mira Studio**: one place to make the phone look and feel the way you want.

## Mira Studio

- **Quick Settings styles**: ColorOS, iOS and One UI layouts on top of Android's own tiles, each with its own edit mode (resize, move, add and remove every tile and widget)
- **Status bar**: Android 17, ColorOS, iOS or One UI icons for Wi-Fi, signal and battery; Dynamic Island; network speed
- **Look**: Liquid Glass, colours from your wallpaper, fonts, lock screen clocks, round icons
- **Motion**: Material 3 Expressive animations everywhere, with Standard, Expressive and Snappy styles and adjustable speed; wavy progress bars and spinners
- **Home screen**: icon shapes and packs, themed icons, gestures, page transitions, hidden apps, layout lock, recents styles
- **Power menu**: Restart System UI, reboot to recovery or bootloader
